## The code

The task is a real computation: find the number in a range whose Collatz chain is the longest. Every number
in the range has to be tried, so the work grows with the range.

<CodeBlock code={collatz} lang="ts" title="collatz.ts" />

The worker searches one segment and returns the answer with its own name. One worker can only search one
segment at a time.

<CodeBlock code={worker} lang="ts" title="collatz.worker.ts" />

The pool is the `maxWorkers` option. `warmUpWorkers` creates every Worker up front, so the first batch does not
pay for starting them.

<CodeBlock code={client} lang="ts" title="client.ts" />

<Callout type="note" title="Each worker has its own memory">
  Workers in a pool do not share variables. State kept inside one Worker is not visible to the others, so a pool
  fits work that depends only on its payload.
</Callout>
