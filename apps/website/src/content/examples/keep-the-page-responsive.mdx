## The code

The function is ordinary TypeScript. Nothing about it knows it will run in a Worker.

<CodeBlock code={math} lang="ts" title="math.ts" />

The Worker file hands that function to `defineWorker` and exports the **type** of the result.

<CodeBlock code={worker} lang="ts" title="math.worker.ts" />

The main thread creates the worker from the file and gets a typed method back. Only the type is imported from
the Worker file, so none of its code ends up in the main bundle.

<CodeBlock code={client} lang="ts" title="client.ts" />

<Callout type="note" title="What the demo measures">
  The heartbeat is a `requestAnimationFrame` loop. A frame can only be drawn when the main thread is free, so the
  longest gap between two frames is the time the page was frozen.
</Callout>
