## The code

`createWorker` receives a function instead of a file. The function returns the methods, and their types are
inferred, so there is no type to export and import.

<CodeBlock code={worker} lang="ts" title="textWorker.ts" />

<Callout type="warning" title="The function cannot use anything from outside">
  The text of the function becomes the source of a real Worker. Variables and imports from the surrounding file
  do not exist there, which is why `words` is defined inside. Send values as payloads, or pass them with the
  `primitiveParameters` option.
</Callout>

The component calls the method on every change and cancels the previous call from the effect cleanup.
