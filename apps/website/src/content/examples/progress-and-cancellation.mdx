## The code

Wrapping the method with `onMessage` gives it the message of the call as second parameter. That is where
progress is reported and where the method learns it was canceled.

<CodeBlock code={worker} lang="ts" title="primes.worker.ts" />

<Callout type="warning" title="A worker has to pause to hear a cancellation">
  A cancellation is a message, and a worker in the middle of a synchronous loop cannot receive messages. That is
  why the method awaits a timer between chunks. Work that never pauses cannot be canceled; it can only be
  restarted with `unwrap(worker).cancelAll(reason, { force: true })`.
</Callout>

On the main thread the call returns a `CancelablePromise`. `onProgress` and `cancel` are methods of that promise.
