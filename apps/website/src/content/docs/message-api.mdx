## Messages instead of methods

`defineWorker` and `createWorker` are built on a message API that you can use directly. It is fully supported,
and both styles can live in the same worker.

<Callout type="note" title="No migration needed">
  Code written with `createEasyWebWorker`, `EasyWebWorker` and `StaticEasyWebWorker` keeps working. Typed methods
  are an addition, not a replacement.
</Callout>

## Latest request wins

For search, previews and autocomplete, an older request is worthless once a newer one exists. `override`
cancels what is pending and sends the new message.

<CodeBlock code={override} lang="ts" title="search.ts" />

`overrideAfterCurrent` lets the call in progress finish and replaces only what is waiting behind it.

With typed workers, both are reached through `unwrap(worker)` and send a message without a method. Handle it in
the worker with `unwrap(worker).onMessage(...)`.

## The methods of EasyWebWorker

| Method                                                         | Purpose                                                         |
| -------------------------------------------------------------- | --------------------------------------------------------------- |
| `send(payload?, transfer?)`                                    | Sends a message to the default handler                          |
| `sendToMethod<TResult, TPayload>(method, payload?, transfer?)` | Sends a message to a named method                               |
| `cancelAll(reason?, { force? })`                               | Cancels every pending call; `force` restarts instead of waiting |
| `override(payload?, reason?, { force? })`                      | Cancels the pending calls and sends a new message               |
| `overrideAfterCurrent(payload?, reason?)`                      | Keeps the current call, cancels the rest, sends a new message   |
| `reboot(reason?)`                                              | Terminates the Workers, rejects pending calls, starts again     |
| `dispose()`                                                    | Cancels pending calls and releases the Workers                  |
